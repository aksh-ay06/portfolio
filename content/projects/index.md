# ⬡ Projects

End-to-end ML and data science work. Each write-up covers the problem, the key decisions, and the results. Code for every project is on [GitHub](https://github.com/aksh-ay06).

## LLMs & Retrieval

- [[projects/arxiv-rag|arXiv RAG]]: hybrid BM25 + vector search, multi-turn chat, a local LLM, and Airflow ingestion (10 Dockerized services).
- [[projects/supply-chain-agents|Supply Chain Intelligence Agents]]: multi-agent LangGraph system with supervisor routing and input/output guardrails.

## MLOps & Production ML

- [[projects/pmmds|PMMDS: ML Monitoring & Drift Detection]]: PSI drift detection, champion/challenger retraining, MLflow registry, Prometheus.
- [[projects/demand-forecasting|Grupo Bimbo Demand Forecasting]]: LightGBM on 74M+ rows, leakage-free features, quantile prediction intervals.
- [[projects/nyc-taxi-mlops|NYC Taxi Fare Prediction on GCP]]: BigQuery + dbt + XGBoost served on Cloud Run, with infrastructure in Terraform.

## Statistics, Causal Inference & Experimentation

- [[projects/brfss-pollution-cancer|Pollution & Cancer (BRFSS 2023)]]: survey-weighted inference vs. predictive lift on 433K respondents.
- [[projects/causal-inference|Causal Inference Toolkit]]: PSM, IPTW, and doubly-robust estimators, with sensitivity analysis and refutation tests.
- [[projects/fantasy-analytics-ab-testing|Fantasy Sports Product Analytics]]: DuckDB pipeline, A/B test analysis, and a Streamlit dashboard.
- [[projects/county-health-ml|County Food Insecurity & Health]]: nested CV, PCA + clustering, bootstrap stability analysis.
